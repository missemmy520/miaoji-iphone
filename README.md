# 喵记

一款用于记录宠物日常进食、排便、排尿、体重和干湿粮库存的原生 iPhone App。深色界面，本地保存，无账号、无广告；可选联网检索医学文献，不上传日记。

**当前源码版本：v0.9（独立湿粮库存与健康小顾问）。最低支持 iOS 17。**

## 功能

- 多宠物资料与切换，各宠物数据独立。
- 进食、排便、排尿、体重记录；补录实际时间，保留自动录入时间；编辑和确认删除。
- 当日情况备注，方便标记换粮、外出及其他特殊情况。
- 首页最近 7 天饮食图、当日摘要和时间线。
- 年、月、周日历，日期跳转与折叠浏览。
- 最近 7 天、30 天、本月统计，按日、周、月汇总进食。
- 干粮、湿粮各自管理库存；自动扣减、校准、消耗记录与低库存提示。
- 健康小顾问：本地记录观察、精选来源问答；可选 Europe PMC 文献检索。不会从克数判断营养达标，不提供诊断和药量。
- 真正的 XLSX 导出，包含每日汇总、进食明细、排便明细、体重明细和排尿明细。

## 下载与安装

发布后请从本仓库 **Releases** 获取对应版本 IPA、版本说明和 SHA256 校验值。尚无 Release 时，可通过 Actions 自行构建。

**未签名 IPA 不能直接点击安装。** Windows 用户可用 AltStore Classic 或 Sideloadly 通过自己的 Apple 账号签名；Mac 用户可用 Xcode 直接编译安装。免费签名通常需要每 7 天续签，并非永久免签安装。

详细步骤：[安装说明](安装说明.md)。

## 使用说明

点击底部「＋」快速记录；在首页、日历查看和编辑当天记录；设置中管理宠物、导出 Excel。

完整说明：[使用说明](使用说明.md)。

数据仅保存在设备本地。**不要卸载存有重要记录的应用。** 更新时保持原签名身份和应用标识；跨安装工具不能保证覆盖更新。Excel 是阅读用导出，当前不能导入恢复，也不是完整数据库备份。

## 数据规则

- 全部按实际发生时间 `eventAt` 和设备当前 Calendar / TimeZone 归属自然日；`createdAt` 记录录入时间，编辑时不改写。
- 缺少记录不代表零摄入、零排便或零体重。体重趋势不补造缺失日数据。
- 日均按有有效记录的日期计算，不把漏记日计作零。
- 干粮库存根据粮袋时间区间和实际干粮记录重算；编辑、删除、补录不会重复扣减。
- 校准后以实际称重为新基准，只扣校准之后的有效干粮记录。
- 预计可食用天数仅为记录日均推算，不是健康判断。

## 从源码构建

Swift、SwiftUI、SwiftData、Swift Charts；无运行时第三方依赖。Excel 使用 Office Open XML 和本地 ZIP 写入。

先下载并解压仓库中的 [MiaoJi-remote-source.zip](MiaoJi-remote-source.zip)。应用源码和 Xcode 工程均在该 ZIP 内。用完整 Xcode 打开解压后的 `MiaoJi.xcodeproj`，选择共享 MiaoJi Scheme。真机运行需要设置自己的 Signing Team。

```sh
bash Scripts/build-iphone.sh
```

脚本要求 macOS 和完整 Xcode，输出未签名真机 IPA 与 SHA256。Windows 不能直接运行 Xcode。修改文件结构后可在 PowerShell 执行 `./create-project.ps1` 更新工程引用。

## 源码压缩包内的项目结构

- `MiaoJi/`：唯一应用源码，按 App、Models、Views、Components、Services、Utilities 分层。
- `MiaoJi/Assets.xcassets/`：已准备好的 App 图标，不需要额外生成图片即可编译。
- `Scripts/`：构建、IPA 校验、SwiftData 备注持久化与迁移检查。
- `.github/workflows/`：手动触发的 macOS 构建工作流。
- `Docs/`：使用、安装与来源核验说明。
- `Distribution/`：本地生成产物，不作为公开源码的一部分。

## v0.8 排尿独立记录

- 本次清理尿团数，单位为坨；同日自动累加。可选常规（约鸡蛋大小）、偏大、偏小、其他，以及团状、扁平、其他。大小和形状独立。
- 未记录不当作零；明确填写零与空白区分。尿团观察不等于精确尿量或排尿次数。
- 首页、日历、时间线、统计和 Excel 独立显示尿团数量，排便原记录保持不变。
- Excel 保留原有列顺序，在每日汇总末尾追加尿团数，并新增第五张排尿明细。

## v0.8.1 饮食柱状图点选明细

首页与统计饮食图支持点击显示精确总量及干粮、湿粮分类克数，保留一位小数；猫条和其他有记录时列出，空缺分类不推断为零。周/月聚合仍按当前筛选范围汇总。

## 健康资料与联网范围

健康小顾问使用精选且可核验的专业来源，当前为 6 个来源、8 个常见主题，并非穷尽所有猫科文献或嵌入通用大模型。每个问答附原文链接和来源信息；[资料来源与限制](健康资料来源.md)。

饮食排泄以外的信息（精神、呕吐、饮水、环境、病史）可以作为咨询描述。未覆盖的问题会明确说明。可选联网查询返回真实文献标题、作者、年份、DOI、原文链接和有限英文摘要节选，不把摘要自动变成医疗结论。只发送独立关键词栏中的内容，咨询原文、档案和日记不自动上传。第三方接口可能不可达或无结果。
